# GuidGenerator

A .NET library for generating RFC-compliant GUIDs and working with their fields.

GuidGenerator covers GUID versions 1–8, field access and replacement, configurable time-based generators, and Native AOT scenarios. An F# companion package adapts the core operations to F# workflows.
